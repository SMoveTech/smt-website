1. What Is S-Move Operations?

S-Move Operations is a software platform that runs an entire removals and storage business from a single system. It handles everything from the moment a customer first makes contact — right through to the day of the move, payment, staff scheduling, and storage invoicing.

Think of it as a control centre connecting four groups of people:

👤 Customers

Get quotes, pay, track their move

🚛 Field Staff

See shifts, log hours, sign off jobs

🖥️ Admin

Manage everything end-to-end

📊 Accountant

Read-only financial view

Each group has their own dedicated portal — a web page tailored to exactly what they need to see and do. All four portals are connected to the same live database, so when anything changes, everyone sees it immediately.

3. The AI System — How It Works

The platform uses Anthropic's Claude AI model across three channels: the website portal chat, inbound phone calls, and SMS text messages. In every case, the AI has access to the customer's live record — so it always knows exactly where the customer is in their journey.

3.2 The AI as a Co-Pilot During Phone Calls

The AI phone line does more than just take new enquiries. Because it has access to the full customer record, it acts as a co-pilot for existing customers — answering any question about their booking over a live phone call.

When the AI collects information (addresses, dates, inventory etc.) it does not just store a conversation — it extracts structured data and writes it directly into the database fields. 7. Security & Data Protection

The platform is built with multiple layers of protection to ensure that customer data is safe and that no user can ever access information they should not see.

Protection

Plain-Language Explanation

Server-side data access + Row-Level Security

Customers and staff never connect to the database directly — the browser only ever talks to S-Move's own server, which holds the privileged database key (that key is never shipped to any browser). Access is scoped so each user only receives their own records, with Row-Level Security applied at the database level where applicable as an additional guard.

Encrypted passwords

All passwords are stored using a one-way encryption process (100,000 rounds of hashing). The original password is never stored and cannot be recovered.

Code obfuscation

The software code that runs in the customer's and staff's browsers is deliberately scrambled before deployment, making it unreadable to anyone trying to inspect or copy it.

Device approval

The admin portal can only be accessed from devices that have been explicitly approved. A new device requires a one-time approval process before it can log in.

Encrypted connection

All data between the user's browser and the server travels over HTTPS — an encrypted connection. Plain HTTP is not permitted.

Payment security

All payments are handled by Stripe, a regulated payment processor. Card details never touch S-Move's servers.

Rate limiting

The system automatically blocks repeated failed login or payment attempts to prevent automated attacks.

8. Key Innovations — What Makes This Platform Unique

The following capabilities distinguish S-Move Operations from conventional removals management software:

8.1 AI That Knows the Full Customer Journey

The AI assistant is not a simple chatbot that answers generic questions. Before every response — whether via chat, phone, or SMS — the system feeds the AI a real-time briefing containing everything known about that customer: their inventory, addresses, quote status, payment status, crew details, and conversation history. The AI responds with full context, not generic scripts.

8.2 Photo-to-Inventory-to-CuFt Pipeline

A customer can photograph the contents of each room on their phone. The AI examines each photo, identifies every item, produces a room-by-room inventory list, and then calculates the total cubic footage of the move. This replaces the need for a surveyor visit in most cases and gives the admin an accurate basis for quoting without visiting the property.

8.3 Live Phone Call + Portal Integration

When a customer is on a live phone call with the AI and simultaneously using the customer portal (for example, uploading photos), the two systems communicate with each other. The AI can speak the results of a photo analysis back to the customer while they are still on the call. This is a real-time bidirectional integration between the voice channel and the web portal.

8.4 Multi-Channel Intake, Single Unified Record

A customer can make first contact by any combination of phone call, SMS text, web chat, or email. All information gathered across every channel is automatically merged into a single customer record. There is no duplicate entry. The admin always sees one unified view regardless of how the customer communicated.

8.5 Controlled Sending + Automated Reminders

Customer-facing documents combine deliberate control with automation where it's safe. The quote and the deposit/full invoice are sent by the admin from a "Send to customer" panel — each click regenerates and previews the exact PDF, sends the paired SMS, and confirms the email landed in the mailbox's Sent folder, with the sent date recorded against the job. Nothing customer-facing is auto-emailed on a status change, so nothing goes out by accident. The genuinely hands-off parts remain automatic: the final balance reminder fires three days before the job, storage invoices generate on the first of every month, and a review request goes out two days after completion.

8.6 Digital Consent at Loading and Unloading

On move day, the customer uses their portal to digitally sign off at two points: when all items have been loaded from the collection address, and when all items have been delivered at the destination. Each signoff is timestamped and permanently recorded. This creates a clear, auditable record of what was agreed by the customer at each stage of the physical move.

8.7 AI Parking Analysis

Before a quote is issued, the system automatically retrieves Google Street View images of both the collection and delivery addresses and passes them to the AI. The AI analyses each image for parking restrictions, access difficulties, and any factors that would affect the cost or logistics of the job. These notes are added to the customer record and are available to both admin and the AI assistant.

10. Glossary of Terms

Term

Plain-English Meaning

AI / Artificial Intelligence

Computer software that can hold a conversation, understand questions, and give intelligent responses. S-Move uses Anthropic's Claude model.

Portal

A web page accessed via a browser, tailored to a specific user (customer, staff, admin, or accountant).

Shift

A single work slot on a specific date, assigned to one staff member for one job.

Rota

The schedule of all shifts and crew assignments for a job or a working day.

Cubic Footage (CuFt)

A measurement of volume — the total amount of space all the customer's belongings will take up in the removal vehicle.

Inventory

A list of all items the customer needs to move, broken down by room.

Stripe

A payment processing company. All card payments and direct debits on the platform go through Stripe.

Direct Debit

A payment method where the customer authorises the system to automatically collect payments from their bank account each month.

Webhook

An automatic notification sent from one software system to another when an event occurs (e.g. Stripe tells S-Move when a payment has been made).

Supabase

The cloud database service that stores all S-Move data securely.

Row-Level Security

A database feature that locks each data record to its owner — no user can access another user's data.

Obfuscation

The process of deliberately scrambling software code so that it cannot be read or copied by others.

SSE (Server-Sent Events)

A technology that allows the server to push instant updates to a user's browser without them having to refresh the page.

Twilio

The telecommunications service that powers the AI phone line and SMS capability.

ConversationRelay

Twilio's technology for routing a live phone call through an AI system in real time.
