13. Rotation & handling

  • Never commit secrets — all values live only in Railway Variables (and locally in an untracked .env).
  • Monzo re-authorises roughly every 90 days (Strong Customer Authentication) — see the Operations & Incident Runbook for the re-auth steps.
  • Stripe webhook secret must be re-copied if the webhook endpoint is recreated.
  • Force IPv4 on all outbound (undici family:4) — Railway's IPv6 egress is broken; this affects Anthropic + any SMTP path.
  • If a key is rotated at the provider, update Railway and redeploy — the app reads env at boot.
