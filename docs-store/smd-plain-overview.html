1. What Is S-Move Dealer?

S-Move Dealer ("SMD", trading as "Your Highstreet Online") is a community-first directory and marketplace built to help independent shops on the local high street thrive by banding them together online. Its guiding idea is simple: "Shop local, discover more."

Unlike a conventional marketplace that ranks whoever pays the most, SMD is a directory first — every independent shop in an area is listed, whether or not they've claimed or paid for anything, so shoppers can always find their local high street online. Businesses can then "claim their listing" and personalise their shop.

🛍️ Shoppers

Browse the directory, buy items, support favourite shops

🏪 Sellers

List items, personalise their shop, get discovered

🚶 Canvassers

Visit shops in person to help them sign up

🖥️ Admin

Approve sellers, moderate, run the business

Each group has its own dedicated app (a Progressive Web App, installable on a phone like a native app), all connected to the same live data.

2. The Directory-First Approach

Most online marketplaces let anyone pay to rank higher. SMD deliberately does the opposite:

What most marketplaces do

What SMD does instead

Only businesses who sign up appear at all

Every shop in the area is listed from day one — signing up just lets a shop claim and personalise its own listing

Paying more money moves a product higher in results

Product ranking is never for sale — a shop's position is earned, based on genuine shopper views and votes

Sponsorship changes what shoppers can find

Sponsorship only buys a place in a sidebar — a form of discovery and community support, never a change to search results

5. Sponsorship — Support, Not Pay-to-Win

Shops can optionally subscribe to a sponsored sidebar placement (a small monthly fee). This buys visibility in a dedicated sidebar slot and a "Pioneer" badge for early supporters — it never changes where a shop's products appear in search or category results. Admin can also grant a free ("comp") sponsor slot to a shop, and every shop that joins during the beta period gets a free month once SMD fully launches.

6. Canvassing — Bringing Shops Online in Person

Because many independent shop owners are busy running their shop, SMD also has a field team that visits shops in person. A canvasser gets an AI-generated briefing before each visit (from a shopfront photo and a web search — likely owner name, how independent the shop is, existing online presence, and good talking points), records the outcome of the visit, and can photograph a shop's products ahead of time. If the shop signs up, that groundwork automatically carries over into their new live shop — nothing needs to be re-entered.

8. Security & Data Protection (Plain Language)

Protection

Plain-English Meaning

Server-side data access

Shoppers, sellers and canvassers never connect to the database directly — only S-Move's own server does, using a privileged key that's never shipped to any browser.

No password for shoppers

Shoppers sign in with a one-time code sent by email or text rather than a password to remember or leak.

Encrypted passwords

Seller, staff and admin passwords are stored using one-way encryption — the original password is never stored and cannot be recovered.

Code obfuscation

The server code is deliberately scrambled before it's deployed, making it far harder for anyone to read or copy.

Device approval for admin

The admin panel can only be opened from a device that's been explicitly approved first.

Encrypted connection

All traffic between a browser and the server travels over HTTPS.

Payment security

All payments go through Stripe, a regulated payment processor — card details never touch S-Move's own servers.

Rate limiting

Repeated failed logins or rapid-fire form submissions are automatically slowed down or blocked.

Database-level locking (Row-Level Security)

On top of the server-side protection above, every single table in the database also has its own row-level access lock switched on — confirmed directly, not assumed. So even in the unlikely event the server's own protection were ever bypassed, the database itself still refuses to hand back data it shouldn't.

These protections are deliberately layered rather than relying on any one of them alone — see the Technical Architecture and Data Model docs for the full detail.

9. Glossary of Terms

Term

Plain-English Meaning

PWA (Progressive Web App)

A website that behaves like an installed app — SMD has five, one each for shoppers, sellers, canvassers, staff and admin.

Directory-first

Every shop in the area is listed by default; signing up lets a shop personalise and manage its own listing rather than being the only way to appear at all.

Earned ranking

A shop or product's position is based on genuine shopper engagement (views, votes), never on how much has been paid.

Sponsored sidebar

A paid discovery slot alongside the directory — a form of visible community support, not a change to search results.

Pioneer

A badge and free month given to shops that join during the beta period.

Canvassing

Visiting shops in person to help sign them up to SMD.

Row-Level Security

A database feature that locks each record to its rightful owner at the database level, as a backup to the server's own access controls.

Stripe

The regulated payment processor used for all card payments, subscriptions and donations.

Webhook

An automatic notification from one system to another when something happens — e.g. Stripe telling SMD that a payment succeeded.
